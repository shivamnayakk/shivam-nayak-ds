### 🏗️ Featured Projects

#### 1. [Asha AI – Healthcare Voice Agent](https://github.com/shivam-nayak-ds/ai-hospital-voice-agent)
Real-time conversational AI system for clinical triage and hospital workflow automation.

*   **Architecture:** Streaming voice pipeline (STT → Reasoning Layer → TTS) with asynchronous backend services
*   **Engineering Focus:** Latency reduction, concurrent request handling, and reliable intent routing under real conversational conditions
*   **Stack:** FastAPI · LangGraph · Streaming pipelines · STT/TTS integration

#### 2. [AI Workforce Automation Platform](https://github.com/shivam-nayak-ds/AI-Workforce-Automation-Platform-)
Multi-agent platform designed to automate business workflows through specialized AI agents.

*   **Architecture:** Supervisor agent coordinating specialist agents (research, outreach, support, scheduling) with structured tool calling
*   **Engineering Focus:** Controllable multi-agent orchestration, state management, and extensible agent design
*   **Stack:** LangGraph · Multi-agent systems · Tool calling · FastAPI

#### 3. [RetailOps – Production ML Pipeline](https://github.com/shivam-nayak-ds/Retail-Ops-End-to-End-Sales-Forecasting-Pipeline)
End-to-end MLOps system for sales forecasting and inventory optimization.

*   **Architecture:** Modular ETL → Training → Validation → Experiment Tracking → Deployment
*   **Engineering Focus:** Reproducibility, experiment tracking, and consistent environments across development and production
*   **Stack:** Python · MLflow · DVC · Docker

#### 4. [Llama-3 Fine-Tuning Pipeline](https://github.com/shivam-nayak-ds/Llama3-Domain-Specific-FineTuning)
Parameter-efficient fine-tuning system for domain adaptation of Llama-3 models.

*   **Architecture:** Dataset preparation → Quantization → LoRA/QLoRA adaptation → Evaluation → Adapter export
*   **Engineering Focus:** Memory-efficient training and practical domain adaptation under resource constraints
*   **Stack:** PyTorch · Hugging Face · LoRA / QLoRA
